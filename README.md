# AI-Sales-Agent
An AI powered Sales Agent that automates lead qualification, priority routing, CRM updates, personalized notifications, and real time sales analytics using AI and workflow automation.

🤖 **What it does:** <br>
🎯 Qualifies and prioritizes leads using AI <br>
🗂️ Automatically updates HubSpot CRM <br>
🔀 Routes leads based on priority <br>
✉️ Generates & sends personalized emails <br>
🔔 Sends Slack messages for sales follow up <br>
📊 Syncs lead data to Looker Studio for real time sales dashboards <br>
